## 🚀 DEPLOYMENT (Choose ONE)

### Option A: Vercel (EASIEST - 5 minutes)

**1. Deploy Code**
```bash
npm install -g vercel
vercel --prod
```

**2. Add API Key in Dashboard**
- Go to: https://vercel.com/dashboard
- Click: Your project
- Settings → Environment Variables
- Add: `VITE_GEMINI_API_KEY` = (your actual key)
- Redeploy

**3. Done!** ✅ Live at: https://bloom-petal-nepal.vercel.app

---

### Option B: Netlify (EASIEST - 5 minutes)

**1. Push to GitHub**
```bash
git add .
git commit -m "Production ready"
git push origin main
```

**2. Connect in Netlify**
- Go to: https://netlify.com
- "Add new site" → GitHub
- Select: BloomAndPetalNepal
- Build: `npm run build`
- Publish: `dist`

**3. Add API Key**
- Site settings → Environment
- `VITE_GEMINI_API_KEY` = (your actual key)

**4. Done!** ✅ Auto-deploys

---

### Option C: Docker (10 minutes)

**1. Build & Test**
```bash
docker build -t bloom-petal .
docker run -p 3000:3000 \
  -e VITE_GEMINI_API_KEY=AIzaSyD_... \
  bloom-petal
```

**2. Push to Server**
```bash
docker push your-registry/bloom-petal
```

**3. Run on Server**
```bash
docker run -p 3000:3000 \
  -e VITE_GEMINI_API_KEY=AIzaSyD_... \
```
