## 📌 PLATFORM DETAILS

### [A] VERCEL (Recommended)
```
1. npm install -g vercel
2. vercel --prod
3. Dashboard → Env Variables
4. Add: VITE_GEMINI_API_KEY = (key)
5. Redeploy
✅ Live at: https://bloom-petal-nepal.vercel.app
```

### [B] NETLIFY (Recommended)
```
1. Push to GitHub
2. netlify.com → Add new site
3. Connect GitHub repo
4. Build: npm run build
5. Publish: dist
6. Site settings → Environment
7. Add: VITE_GEMINI_API_KEY = (key)
✅ Live at: https://bloom-petal.netlify.app
```

### [C] GITHUB PAGES (Free)
```
1. Push to GitHub
2. Settings → Pages
3. Build from main branch
4. ⚠️ Limited (static site only)
✅ Live at: https://username.github.io/BloomAndPetalNepal
```

### [D] DOCKER (Full Control)
```
1. docker build -t bloom-petal .
2. docker run -p 3000:3000 \
     -e VITE_GEMINI_API_KEY=AIzaSy... \
     bloom-petal
✅ Running at: http://localhost:3000
```
