## 🌸 Overview

**Bloom & Petal Nepal** is a modern, user-friendly e-commerce platform tailored for florists and customers in Nepal. Enjoy seamless shopping, easy cart management, and a beautiful interface designed for flower lovers and sellers.

---


## 🚀 Features

- ⚡ Modern React + Vite frontend
- 🛒 Secure checkout and cart management
- 🛠️ Admin dashboard for product management
- 📱 Responsive design for all devices

---


## 🏁 Getting Started


### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)


### Installation

1. **Clone the repository:**
  ```bash
  git clone https://github.com/NiteshChaudhari-exe/BloomAndPetalNepal.git
  
  ```
2. **Install dependencies:**
  ```bash
  npm install
  ```
3. **Set up environment variables (optional):**
  - Create a `.env.local` file in the root directory if you need to store secrets or API keys for your own integrations.
4. **Run the development server:**
  ```bash
  npm run dev
  ```

The app will be available at [http://localhost:5173](http://localhost:5173) (default Vite port).

## 💡 Usage

- Visit the homepage to browse products and featured flowers.
- Add items to your cart and proceed to secure checkout.
- Admins can log in to manage products and view orders.
